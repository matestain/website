# website

Public landing page for [matestain.com](https://matestain.com).

> **Status: Live.** Minimal HTML/CSS landing page at [matestain.com](https://matestain.com), with a functional email capture form. Website v1 (the full site) is still pending development — see `CLAUDE.md` for current infrastructure details.

## Planned Stack

- **Phase 1 (current):** Static HTML/CSS — fast, no dependencies, deployable anywhere
- **Phase 2 (optional):** Next.js — if dynamic content or SSR becomes necessary

The decision to upgrade to Next.js will be made when there is a concrete reason, not before.

## Deployment

- Domain: `matestain.com` (registered via Cloudflare)
- Hosting: Cloudflare Pages, Git-connected to `main`, auto-deploy on push

## Who it's for

Public audience — potential clients, partners, and anyone interested in what MATESTAIN does.
